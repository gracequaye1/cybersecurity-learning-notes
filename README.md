Topics Covered
1. Security Frameworks

Security frameworks provide guidelines for identifying, managing, and reducing cybersecurity risks.

The four core activities I learned about are:

Identifying and documenting security goals.
Setting guidelines to achieve those goals.
Implementing security processes.
Monitoring and communicating results.

Examples include the NIST Cybersecurity Framework (CSF) and the NIST Risk Management Framework (RMF).

2. Security Controls

Security controls are safeguards designed to reduce specific security risks.

Examples include:

Access controls and permissions.
Firewalls.
Multifactor authentication.
Security awareness training.
Regular software updates.
3. The CIA Triad

The CIA Triad describes three foundational principles of information security.

Confidentiality: Information is accessible only to authorized users.
Integrity: Information remains accurate and complete.
Availability: Systems and information are accessible when needed by authorized users.
4. Compliance and Regulations

Compliance involves following applicable laws, regulations, standards, and organizational policies.

Some important examples are:

GDPR: Data protection and privacy regulation in the European Union.
HIPAA: U.S. law establishing protections for certain health information.
PCI DSS: Security standard for payment card data.
NIST CSF: A framework for managing cybersecurity risks.

Different requirements apply depending on the organization, the data it handles, and the relevant jurisdiction.

5. Cybersecurity Ethics

Cybersecurity professionals have a responsibility to use their access appropriately and protect sensitive information.

Important principles include:

Respecting confidentiality and privacy.
Following organizational policies and applicable laws.
Avoiding unauthorized access and misuse of privileges.
Preserving evidence and reporting security incidents appropriately.
Using authorized defensive measures rather than launching unauthorized counterattacks.
